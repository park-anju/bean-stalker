# Finish Task

For `$ARGUMENTS`:
1. Re-read acceptance/tests.
2. Run exact relevant validation commands.
3. Review provider credential, privacy, error and cost implications.
4. Update [[Traceability Matrix]] and [[Implementation Handoffs]].
5. Mark DONE only with evidence.
6. Update [[Current Project State]], [[Current Execution Focus]] and blockers.
7. Record significant design divergence through `/record-decision`.
