## Project adaptation

## Resume-project constraints

- target delivery window: three days;
- must be demoable and explainable in an interview;
- should demonstrate external API integration, geolocation, state management, map UI, error handling and secure credential boundaries;
- avoid scope that produces a half-finished product.
