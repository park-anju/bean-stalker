# Glossary Index

| Term | Meaning |
|---|---|
| **Search center** | Latitude/longitude used as the origin for Nearby Search. |
| **Search radius** | Maximum search circle radius requested by the app. |
| **Provider result** | A cafe record returned by Google Places before normalization. |
| **Cafe card** | Bean Stalker's normalized UI representation of a place. |
| **Open status** | `open`, `closed`, or `unknown` based only on available provider data. |
| **Favourite** | A locally saved cafe reference on the current browser/device. |
| **Field mask** | Explicit list of Places fields requested from Google. |
| **Browser key** | Website-restricted credential used by client-side Maps JavaScript API. |
| **Server key** | Credential kept server-side for Places web-service calls. |
| **Stale result** | Cached data old enough to be revalidated under [[Search Result Freshness]]. |
| **P0** | Three-day resume MVP. |

See [[Cafe Discovery Model]], [[API Key Boundaries]] and [[Ranking and Filtering Rules]].
